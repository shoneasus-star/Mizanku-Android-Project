Fitur Utama

  • Kasir cepat dengan keranjang dan pilihan Tunai, QRIS, atau Debit
  • Kelola produk, kategori, foto, dan stok
  • Riwayat transaksi dan grafik omset per tahun, bulan, tanggal
  • Kirim laporan penjualan ke Microsoft Word
  • Cetak struk lewat printer Bluetooth atau browser
  • Cadangkan dan pulihkan data dalam satu file

Cara Singkat Memakai

  1. Isi profil usaha, logo, dan data struk di menu Pengaturan Struk.
  2. Tambahkan produk di menu Kelola Produk.
  3. Pilih produk di Kasir, buka keranjang, pilih metode bayar, lalu selesaikan.
  4. Lihat omset di Riwayat & Laporan, lalu kirim ke Word bila perlu.

Data tersimpan di browser perangkat ini. Cadangkan secara berkala agar aman bila browser dibersihkan atau ganti perangkat.
